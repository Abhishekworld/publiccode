Language-specific Headers & Footers

Available placeholders:
  • {lang} - Language code
  • {title} - Page title
  • {description} - Page description
  • {keywords} - Page keywords
  • {content} - Page content
  • {canonical} - Canonical URL
  • {hreflangTags} - Hreflang tags
  • {pageStyle} - Page-specific CSS
  • {siteName} - Site name
  • {headContent} - Custom head content
  • {ogImage} - OG image URL
  • {ogImageWidth} - OG image width
  • {ogImageHeight} - OG image height
  • {ogImageType} - OG image type
  • {header} - Language-specific header
  • {footer} - Language-specific footer
